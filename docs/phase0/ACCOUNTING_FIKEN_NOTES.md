# Accounting integration notes (Fiken)

Status: **research notes — everything here is to verify with the accountant and Fiken.** Findings
collected from public vendor sources on **2026-09-18**; endpoint names, version, rate limits and the
add-on price are not a confirmed contract until Fiken confirms them.

## 1. Current state

- **Aquarela uses Fiken** as its cloud accounting system.
- The **Fiken API module is already enabled** for the company (owner statement, 2026-09-18). The module
  is an add-on activated under **Foretak → Tilleggstjenester** (commonly around **99 kr/month** — verify
  the current price); no further activation is needed before integration work.

## 2. Authentication

- Fiken's API is authenticated with **OAuth 2.0** (`Authorization: Bearer <token>`) or with a
  **personal API token** used as a Bearer token.
- Personal tokens are created in Fiken under **Rediger konto → API → Personlige API-nøkler**.
- **The token must be stored in the secret manager** (per `07_SECURITY_AND_NFR.md`), never committed to
  the repository and never written to logs. Credential ownership follows `DEC-015`.
- This is a **write-capable integration** (`DEC-015`): Fiken is an approved write target only for
  operations explicitly approved per operation, from an approved internal change, as an idempotent
  publish job with confirmation read-back, audit, rollback and failure alerts.

## 3. API surface

- REST API base URL: `https://api.fiken.no/api/v2/`
- Interactive docs: `https://api.fiken.no/api/v2/docs/`
- **OpenAPI/Swagger spec (machine-readable):** `https://api.fiken.no/api/v2/docs/swagger.yaml` — a
  generated TypeScript client is feasible from this spec.
- An autogenerated **Node SDK** exists (`@okane-no/fiken-sdk`), plus community tooling.
- Typical API areas: sales/invoices, customers/contacts, payments, purchases, products and bank — enough
  both to read accounting data and to push summarized sales/expense documents.
- **Caveat:** verify endpoint names and API version with Fiken before relying on them.

### Fiken documentation

- The **interactive docs at `https://api.fiken.no/api/v2/docs/` are a JavaScript single-page app**, not
  directly scrapeable — do not try to crawl them.
- Use the **machine-readable OpenAPI/Swagger spec**
  (`https://api.fiken.no/api/v2/docs/swagger.yaml`) as the **source of truth** to enumerate the available
  endpoints and to **generate a TypeScript client** for the integration.
- Base URL and authentication are as recorded above (`https://api.fiken.no/api/v2/`; OAuth 2.0 or a
  personal Bearer token).

## 4. Effect on DEC-016

The monthly reconciliation package (structured CSV/JSON with snapshot ID, generated time, scope and
checksums, plus reference links to source records) can be delivered **as files and/or pushed via the
Fiken API** for approved operations. The **statutory SAF-T shape remains a file export** — SAF-T is a
file format for the tax authority, not an API posting.

## 5. What to confirm with the accountant / Fiken

- The **exact API operations permitted** (which document types may be posted, and whether reads are
  permitted beyond those).
- Whether **sales summaries should be booked as one monthly document** or per day/location.
- **Account/cost-centre mapping** (kontoplan) and **VAT-code mapping**.
- Whether the accountant **prefers API posting or the validated file package** (or both, with one as the
  system of record).
